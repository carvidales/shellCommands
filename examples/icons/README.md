# Script logos

These are compact (64 × 64) PNG versions of the generated logos, intended for
the optional **Script icon** field in the Shell Commands app.

| Logo | Suggested script |
| --- | --- |
| [kill-port.png](kill-port.png) | Kill Port / Stop processes listening on a port |
| [check-port.png](check-port.png) | Check Port / Find listeners on a port |
| [api-response-time.png](api-response-time.png) | API Response Time / curl URL timing |
| [open-websites.png](open-websites.png) | Open Websites / Browser launcher |
| [wsl-claude-launcher.png](wsl-claude-launcher.png) | WSL Claude Launcher / AI terminal launcher |

To use one, open the script's **Edit** page, choose the file under
**Script icon (optional)**, and click **Save**.

Icons are deliberately **not automatically assigned**. Script records and
uploads are local to each installation; GitHub doesn't have access to them.
The app stores uploaded icons under the gitignored `scripts/.icons/` folder.
